# JavaWeb 导读：一条由浅入深的通关路线

> 本目录按「**Java 内功先行，再进入 Web 与 Spring 框架**」的顺序组织。先打底，再上框架，最后实战收尾，层层递进、抽丝剥茧。

## 为什么这样排序

很多人学 Spring 一上来就背 `@Autowired`、`@Transactional`，结果处处踩坑——因为**框架的每一行魔法，底层都是 Java 的高级特性在支撑**：

- 不懂接口多态，就看不懂依赖注入；
- 不懂反射，就看不懂 IoC 容器；
- 不懂异常体系，就踩不中事务回滚的坑。

所以本目录把「Java 内功」放在最前面，先补齐底层地基，再逐步往上盖 Web 与框架的高楼。

## 推荐学习路径

1. **先读 [01-Java内功](01-Java内功.md)**——把接口多态、反射、注解这些「零件」认全，它们是后续所有框架概念的语言。
2. **再读 [02-Servlet与Tomcat](02-Servlet与Tomcat.md)**——建立「请求从浏览器进来，到返回响应」的完整物理图景。
3. **接着读 [03-SpringMVC](03-SpringMVC.md)**——看 Spring 如何用一个 `DispatcherServlet` 把上面的流程统一收口。
4. **然后读 [04-IoC-DI](04-IoC-DI.md)**——理解 Spring 最核心的思想：对象不再由你 `new`，由容器创建和注入。
5. **进阶读 [05-SpringBoot](05-SpringBoot.md)**——在 IoC 的基础上，看 Spring Boot 如何用「约定大于配置」消灭配置地狱。
6. **最后读 [06-AOP与数据库](06-AOP与数据库.md)**——用 AOP 和事务把横切逻辑抽离，再落地到 JPA / MyBatis 两种数据访问风格。

## 一句话串联

**反射 + 注解** 造出了 IoC 容器（[01](01-Java内功.md) / [04](04-IoC-DI.md)）；IoC 容器组装出 `DispatcherServlet`，统一处理请求（[03](03-SpringMVC.md)），而请求的物理底座是 Servlet 与 Tomcat（[02](02-Servlet与Tomcat.md)）；Spring Boot 把这些配置自动装配起来（[05](05-SpringBoot.md)）；AOP 用代理把日志、事务等横切逻辑织入，事务和持久层再落到数据库（[06](06-AOP与数据库.md)）。
