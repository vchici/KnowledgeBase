## 学习主线

1. **单库核心（01 → 06）**：架构 → 索引 → 查询执行 → 事务 → 锁 → 日志。顺序就是一条 SQL 的生命周期：进来（架构）→ 找数据（索引）→ 执行（Join）→ 保证正确（事务/锁）→ 保证不丢（日志）。
2. **设计（07）**：会查了还不够，建表时把字段和表结构定对，后面的索引和事务才有发挥空间。
3. **工程实践（08）**：跳出单条 SQL，看应用层怎么用数据库做可靠的任务流转。
4. **演进（09）**：AI 时代数据库往哪个方向变。
