复制一个可变对象时，有**赋值**、**浅拷贝（shallow copy）**、**深拷贝（deep copy）**三种层次，差别只在「嵌套的可变对象」上。搞错会改到不该改的数据。

# 1. 三种方式先分清

| 方式 | 写法 | 嵌套对象是否共享 |
| --- | --- | --- |
| 赋值 | `b = a` | 完全共享（同一个对象） |
| 浅拷贝 | `copy.copy(a)` / `a.copy()` / `a[:]` | 共享 |
| 深拷贝 | `copy.deepcopy(a)` | 不共享（完全独立） |

关键结论：**浅拷贝只复制最外层，深拷贝连嵌套对象一起复制**。

# 2. 赋值 vs 拷贝

赋值只是多一个名字指向同一个对象，改一个另一个也变：

```python-run
a = [1, 2, 3]
b = a                 # 赋值：同一个对象
b.append(4)
print("赋值后 a:", a, "b:", b, "同一对象?", a is b)   # 都变，True
```

浅拷贝会复制出**新的一层**，改外层互不影响：

```python-run
import copy
a = [1, 2, 3]
b = copy.copy(a)      # 浅拷贝：新的外层 list
b.append(4)
print("浅拷贝后 a:", a, "b:", b, "同一对象?", a is b)   # a 不变，False
```

# 3. 浅拷贝的坑：嵌套对象仍共享

当 list 里还有 list（或 dict、set），浅拷贝只复制外层，内层对象还是同一个：

```python-run
import copy

a = [[1, 2], [3, 4]]
b = copy.copy(a)      # 浅拷贝

b[0].append(99)       # 改「内层」list
print("浅拷贝 a:", a)  # [[1, 2, 99], [3, 4]]，a 的内层也被改了！
print("内层同一对象?", a[0] is b[0])   # True
```

# 4. 深拷贝：完全独立

`deepcopy` 递归复制所有嵌套对象，改任何一层都不影响对方：

```python-run
import copy

a = [[1, 2], [3, 4]]
b = copy.deepcopy(a)  # 深拷贝

b[0].append(99)
print("深拷贝 a:", a)  # [[1, 2], [3, 4]]，a 完全不变
print("内层同一对象?", a[0] is b[0])   # False
```

# 5. 常见浅拷贝写法

这些「复制 list」的写法其实都是浅拷贝，遇到嵌套对象同样会共享内层：

```python-run
a = [[1, 2], [3, 4]]

b1 = a[:]             # 切片
b2 = a.copy()         # copy 方法
b3 = list(a)          # list() 构造

b1[0].append(99)
print("切片后 a:", a)   # 内层仍被改，说明是浅拷贝
print(a[0] is b2[0], a[0] is b3[0])   # True True
```

# 6. 同样的规则适用于 dict / 嵌套容器

```python-run
import copy

d = {"k": [1, 2, 3], "n": 5}
d2 = copy.copy(d)         # 浅拷贝：value 里的 list 仍共享
d2["k"].append(99)
print("浅拷贝 d:", d)      # {'k': [1, 2, 3, 99], 'n': 5}

d3 = copy.deepcopy(d)     # 深拷贝：完全独立
d3["k"].append(100)
print("深拷贝 d:", d)      # 仍 {'k': [1, 2, 3, 99], 'n': 5}
```

# 7. 何时用哪个

| 场景 | 选择 |
| --- | --- |
| 只是换个名字、想共享同一份数据 | 赋值 `b = a` |
| 复制一层，元素是 int/str/tuple 等不可变对象 | 浅拷贝即可（`a.copy()`） |
| 复制嵌套的可变结构，要完全独立 | 深拷贝 `copy.deepcopy` |
| 自定义对象、复杂引用结构 | 深拷贝 |

多数情况（一层、不可变元素）用 `a.copy()` 就够；只有出现「嵌套可变对象」才需要 `deepcopy`。

# 8. 易混淆点

- `b = a` 不是拷贝，是别名，`a is b` 为 `True`
- `a[:]`、`a.copy()`、`list(a)` 都是**浅拷贝**，不是深拷贝
- 判断是否独立，看 `a[0] is b[0]`（内层身份），而不是 `a is b`
- `deepcopy` 能处理循环引用、自定义对象，但更慢、更占内存，不要滥用

```python-run
import copy

a = [[1, 2], [3, 4]]
b = copy.deepcopy(a)

# 外层、内层都不同对象
print("外层不同?", a is b)        # False
print("内层不同?", a[0] is b[0])  # False
```
