**推导式（comprehension）** 用一句话从可迭代对象构造出新容器；**生成器（generator）** 则按需、惰性地逐个产出元素，省内存。二者是 Python 高频写法，能显著精简代码。

# 1. 列表推导式

语法 `[表达式 for 变量 in 可迭代对象 if 条件]`。把「for 循环 + append」压缩成一行：

```python-run
# 传统写法
squares = []
for x in range(10):
    if x % 2 == 0:
        squares.append(x * x)

# 推导式等价写法
squares = [x * x for x in range(10) if x % 2 == 0]
print(squares)
```

嵌套循环也能写，但别堆太深以免难读：

```python-run
pairs = [(a, b) for a in "AB" for b in "12"]
print(pairs)   # [('A', '1'), ('A', '2'), ('B', '1'), ('B', '2')]
```

# 2. 集合与字典推导式

把外层括号换成 `{}` 即可，规则一致：

```python-run
# 集合推导式（自动去重）
nums = [1, 2, 2, 3, 3, 3]
unique = {x for x in nums}
print("集合推导式:", unique)

# 字典推导式
words = ["apple", "banana", "cherry"]
lengths = {w: len(w) for w in words}
print("字典推导式:", lengths)

# 用推导式做计数（配合 Counter 更简洁，见三大容器篇）
```

# 3. 生成器表达式

把列表推导式的 `[]` 换成 `()`，得到**生成器表达式**。它不立刻算出所有元素，而是用到时才算：

```python-run
gen = (x * x for x in range(5))
print("类型:", type(gen).__name__)   # generator
print("逐个取:", next(gen), next(gen))
print("其余:", list(gen))            # 已消费的不会再回来
```

生成器是**一次性**的，遍历完就空了。需要反复用就转成 list 或重新生成。

# 4. 惰性求值与内存优势

列表推导式一次性把全部元素塞进内存；生成器只保留当前元素。处理大数据时差距巨大：

```python-run
import sys

big_list = [x * x for x in range(1_000_000)]
big_gen = (x * x for x in range(1_000_000))

print(f"列表内存: {sys.getsizeof(big_list):,} bytes")
print(f"生成器内存: {sys.getsizeof(big_gen):,} bytes")   # 几乎不占空间
```

# 5. yield 与生成器函数

函数里只要出现 `yield`，它就不再是普通函数，调用它返回的是生成器，不会立刻执行函数体：

```python-run
def countdown(n):
    print("开始计数")
    while n > 0:
        yield n      # 每次 yield 暂停，下次 next 从这继续
        n -= 1

gen = countdown(3)
print("尚未执行，先拿到:", gen)
print(next(gen))
print(next(gen))
print(list(gen))     # 剩下的 1
```

# 6. 用生成器处理大文件 / 无限序列

生成器天然适合「无限序列」和「流式处理」，不会撑爆内存：

```python-run
def fibonacci():
    a, b = 0, 1
    while True:
        yield a
        a, b = b, a + b

fib = fibonacci()
print("前 8 个斐波那契:", [next(fib) for _ in range(8)])
```

# 7. 何时用哪个

| 需求 | 选择 |
| --- | --- |
| 需要多次遍历、按下标访问、求长度 | list（用列表推导式） |
| 去重 | set（集合推导式） |
| 键值映射 | dict（字典推导式） |
| 数据量大、只需遍历一次、或无限序列 | 生成器（表达式或 `yield` 函数） |
| 需要传给 `sum` / `max` / `join` 等 | 生成器表达式即可，省一层 list |

```python-run
total = sum(x * x for x in range(1, 101))   # 不建 list，直接求和
print("1~100 平方和:", total)
```

# 8. 易混淆点

- 列表推导式 `[]` 立刻求值、占内存；生成器表达式 `()` 惰性求值、一次性
- 生成器只能遍历一次，第二次遍历为空
- `next()` 取完会抛 `StopIteration`，`for` 循环会自动处理它
- 推导式里的 `if` 是过滤条件；`if ... else` 放在表达式位置则是条件取值

```python-run
# if 在末尾 = 过滤
evens = [x for x in range(10) if x % 2 == 0]

# if/else 在前 = 每个元素都取值
labels = ["偶数" if x % 2 == 0 else "奇数" for x in range(5)]

print(evens)
print(labels)
```
