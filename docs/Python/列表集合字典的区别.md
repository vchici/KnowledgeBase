Python 内置三大容器：**list（列表）**、**set（集合）**、**dict（字典）**。它们各司其职，选错容器往往意味着又慢又难读。下面从本质差异到使用场景逐一对比。

# 核心区别一览

| 对比项 | list | set | dict |
| --- | --- | --- | --- |
| 语法 | `[]`，如 `[1, 2, 3]` | `{}`，如 `{1, 2, 3}` | `{k: v}`，如 `{"a": 1}` |
| 有序性 | ✅ 有序，靠索引访问 | ❌ 无序（3.7+ 保留插入序） | ✅ 3.7+ 有序（按插入序） |
| 元素唯一 | ❌ 允许重复 | ✅ 自动去重 | key 唯一，value 可重复 |
| 元素要求 | 任意对象 | 必须**可哈希**（不可变） | key 必须**可哈希** |
| 索引/下标 | ✅ `lst[0]` | ❌ 无下标 | ❌ 无下标，用 key 取 |
| 成员判断速度 | O(n)，较慢 | O(1)，快 | O(1)，快（查 key） |
| 增删速度 | 中间插入 O(n)，末尾 O(1) | O(1) | O(1) |
| 典型用途 | 有序、可重复、需索引 | 去重、集合运算 | 键值映射、计数 |

# 1. 有序性与索引

- **list**：严格有序，靠下标 `lst[0]` 访问，支持切片。
- **set**：无下标，不能 `s[0]`，只能遍历或用 `in` 判断。
- **dict**：无下标，用 key 访问 `d["a"]`。Python 3.7 起按插入顺序遍历。

```python-run
lst = [3, 1, 2, 1]
print("list 下标访问:", lst[0], "切片:", lst[1:3])

s = {3, 1, 2, 1}
print("set 遍历:", list(s))     # 元素唯一，顺序不保证

d = {"a": 1, "b": 2, "c": 3}
print("dict 取值:", d["a"], "键顺序:", list(d))
```

# 2. 唯一性（去重）

set 的核心价值就是**自动去重**。list 允许重复，dict 的 value 允许重复但 key 唯一。

```python-run
nums = [1, 2, 2, 3, 3, 3]
unique = list(set(nums))        # 去重，但顺序会丢失
print("去重后（无序）:", unique)

# 去重且保留顺序
seen = set()
ordered = [x for x in nums if not (x in seen or seen.add(x))]
print("去重且保序:", ordered)
```

# 3. 元素的可哈希性

set 的元素、dict 的 key 都必须是**可哈希**对象（通常是不可变的：int、str、tuple）。list 和 dict 本身可变、不可哈希，不能放进 set，也不能作 dict 的 key。

```python-run
s = {(1, 2), 3, "x"}            # ✅ 都是可哈希的
print("合法的 set:", s)

try:
    {[1, 2]}                    # ❌ list 不可哈希
except TypeError as e:
    print("list 不能进 set:", e)

try:
    {{"a": 1}: "v"}             # ❌ dict 不可哈希
except TypeError as e:
    print("dict 不能作 key:", e)
```

# 4. 性能差异

成员判断 `in` 最能体现差距：list 要逐个比，O(n)；set 和 dict 基于哈希，O(1)。数据量大时差距可达数百倍。

```python-run
import time

n = 100_000
lst = list(range(n))
s = set(lst)
target = n - 1

t0 = time.perf_counter()
for _ in range(1000):
    target in lst
t_list = time.perf_counter() - t0

t0 = time.perf_counter()
for _ in range(1000):
    target in s
t_set = time.perf_counter() - t0

print(f"list 查找: {t_list:.4f}s")
print(f"set  查找: {t_set:.4f}s")
print(f"set 比 list 快约 {t_list / t_set:.0f} 倍")
```

# 5. dict 的典型用法

dict 不只是存映射，还常用于**计数**、**分组**。配合 `defaultdict` 和 `Counter` 可以更简洁。

```python-run
from collections import defaultdict, Counter

words = ["apple", "banana", "apple", "cherry", "banana", "apple"]

# 手动计数
cnt = {}
for w in words:
    cnt[w] = cnt.get(w, 0) + 1
print("手动计数:", cnt)

# 更简洁的写法
print("Counter:", dict(Counter(words)))

# 按首字母分组
groups = defaultdict(list)
for w in words:
    groups[w[0]].append(w)
print("按首字母分组:", dict(groups))
```

# 6. 使用场景速查

| 需求 | 推荐容器 |
| --- | --- |
| 有序、可重复、要按下标访问 | list |
| 去重、集合运算（交集/并集/差集） | set |
| 键值映射、计数、分组、快速查找 | dict |
| 需要频繁 `in` 判断且数据量大 | set（或 dict 的 key） |

# 7. 易混淆点

- `{}` 默认是**空字典**，不是空集合；空集合要写 `set()`
- set 没有下标，`s[0]` 会抛 `TypeError: 'set' object is not subscriptable`
- dict 的 key 可以是 tuple（可哈希），但不能是 list（不可哈希）
- 去重用 `set()` 会丢失原顺序，需要保序时用「seen set + 列表推导」
- 集合运算写法：`a & b`（交）、`a | b`（并）、`a - b`（差）、`a ^ b`（对称差）

```python-run
print("{} 的类型:", type({}).__name__)        # dict
print("set() 的类型:", type(set()).__name__)   # set

a = {1, 2, 3}
b = {2, 3, 4}
print("交集:", a & b, "并集:", a | b, "差集:", a - b, "对称差:", a ^ b)
```
