在 Python 中，我们常说的「数组」通常指 **list（列表）**。严格意义上的数组有两种：

- 标准库的 **`array.array`**：元素类型固定，更像 C 语言数组
- 第三方库 numpy 的 **`ndarray`**：科学计算用的高性能数组

而 **tuple（元组）** 是另一种内置序列。下面重点对比 `tuple` 和 `list`。

# 核心区别一览

| 对比项 | tuple（元组） | list（列表） |
| --- | --- | --- |
| 语法 | `()`，如 `(1, 2, 3)` | `[]`，如 `[1, 2, 3]` |
| 可变性 | **不可变**（immutable） | **可变**（mutable） |
| 可哈希（可作 dict key / set 元素） | ✅ 可以 | ❌ 不行 |
| 内存占用 | 更小 | 更大 |
| 创建/访问速度 | 更快 | 稍慢 |
| 可用方法 | 少（count / index） | 多（append / remove / sort…） |
| 典型用途 | 固定结构、记录、函数返回多值 | 动态集合、需要增删改的数据 |

# 1. 可变性（最关键的区别）

- **list 可以增删改**：`lst[0] = 100`、`lst.append(4)` 都是合法的
- **tuple 创建后不可变**：任何修改都会抛 `TypeError: 'tuple' object does not support item assignment`

这也是二者最本质的差异，其余差别（性能、哈希、内存）大多由此衍生。

```python-run
lst = [1, 2, 3]
lst[0] = 100            # ✅ list 可以修改
print("list 修改后:", lst)

tup = (1, 2, 3)
try:
    tup[0] = 100        # ❌ tuple 不可变
except TypeError as e:
    print("tuple 不可变:", e)
```

# 2. 可哈希性

只有不可变对象才能被哈希。因此：

- `(1, 2)` 可以作 `dict` 的 key，可以放进 `set`
- `[1, 2]` 不行，会抛 `TypeError: unhashable type: 'list'`

```python-run
d = {(1, 2): "坐标点"}  # ✅ tuple 可哈希
print("tuple 作 dict key:", d[(1, 2)])

try:
    {[1, 2]: "x"}       # ❌ list 不可哈希
except TypeError as e:
    print("list 不能作 key:", e)
```

# 3. 性能与内存

tuple 内部结构比 list 简单，创建更快、占用内存更小。在需要大量创建的场景（如循环里造坐标）优先用 tuple。

```python-run
import sys
lst = [1, 2, 3, 4, 5]
tup = (1, 2, 3, 4, 5)
print(f"list 内存:  {sys.getsizeof(lst)} bytes")
print(f"tuple 内存: {sys.getsizeof(tup)} bytes")

from array import array          # 标准库的“真数组”：元素类型固定
arr = array("i", [1, 2, 3])      # "i" = 有符号整型
print("array.array:", arr, "—— 类型固定、更省内存")
```

# 4. 使用场景

| 场景 | 推荐 |
| --- | --- |
| 函数返回多个值 | tuple（默认就是返回元组） |
| 坐标、RGB 颜色等固定结构 | tuple |
| 作为 dict 的 key | tuple |
| 动态收集数据、排序、增删 | list |
| 同类型的大量数值 | `array.array`（省内存）或 numpy `ndarray`（科学计算） |

# 5. 易混淆点

- `(1)` 不是元组，是整数；单元素元组要写成 `(1,)`
- `[]` 和 `()` 可以互换用于索引、切片、遍历、拼接、解包
- 元组里若包含可变元素（如 `([1], 2)`），该元组本身依然不可变，但内部 list 仍可修改

```python-run
print("(1) 的类型:", type((1)).__name__)
print("(1,) 的类型:", type((1,)).__name__)

t = ([1], 2)
t[0].append(99)       # 元组本身不可变，但内部 list 可以改
print("元组内部的可变元素:", t)
```
