Python 是面向对象语言，万物皆对象。**类（class）** 是对象的模板，**对象（实例 instance）** 是用模板造出来的具体实体。掌握类与对象是写出结构化、可复用代码的基础。

# 1. 定义类与创建对象

用 `class` 定义，`__init__` 是构造方法（初始化方法），`self` 指向当前实例：

```python-run
class Dog:
    def __init__(self, name, age):
        self.name = name   # self.name 是实例属性
        self.age = age

    def bark(self):
        return f"{self.name} 在叫：汪汪"

# 创建对象（实例化）
d1 = Dog("旺财", 3)
d2 = Dog("来福", 1)

print(d1.name, d1.age)     # 旺财 3
print(d1.bark())           # 旺财 在叫：汪汪
print(d2.bark())           # 来福 在叫：汪汪
```

- `__init__` 不是必须的，但几乎总用它来给实例设置初始属性。
- 调用 `d1.bark()` 时，Python 会自动把 `d1` 传给 `self`，所以方法里不用手动传。

# 2. 实例属性 vs 类属性

**实例属性** 每个对象各自一份；**类属性** 所有实例共享，属于类本身：

```python-run
class Dog:
    species = "犬科"        # 类属性，所有实例共享

    def __init__(self, name):
        self.name = name    # 实例属性，各自独立

a = Dog("旺财")
b = Dog("来福")

print(a.species, b.species)   # 犬科 犬科
print(a.name, b.name)         # 旺财 来福

Dog.species = "犬属"          # 修改类属性，所有实例都变
print(a.species, b.species)   # 犬属 犬属
```

注意：如果通过 `a.species = "x"` 赋值，只会给 `a` 新建一个实例属性，不会改到类属性。

# 3. 方法与 `self`

实例方法第一个参数约定写 `self`（其实叫什么都行，但强烈建议用 `self`）。方法可以读改实例属性：

```python-run
class Counter:
    def __init__(self):
        self.count = 0

    def add(self, n=1):
        self.count += n
        return self.count

c = Counter()
print(c.add())      # 1
print(c.add(3))     # 4
print(c.count)      # 4，属性可直接访问
```

# 4. 常用特殊方法（魔法方法）

以双下划线开头结尾的方法，Python 会在特定时机自动调用：

| 方法 | 触发时机 |
| --- | --- |
| `__init__` | 创建实例时 |
| `__str__` | `print(obj)` / `str(obj)` |
| `__repr__` | 调试、交互式直接显示 |
| `__len__` | `len(obj)` |
| `__eq__` | `==` 比较 |

```python-run
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __str__(self):
        return f"Point({self.x}, {self.y})"

    def __repr__(self):
        return f"Point({self.x}, {self.y})"

    def __len__(self):
        return 2

    def __eq__(self, other):
        return self.x == other.x and self.y == other.y

p = Point(1, 2)
print(p)                 # Point(1, 2)  调用了 __str__
print(len(p))            # 2           调用了 __len__
print(p == Point(1, 2))  # True        调用了 __eq__
```

不实现 `__eq__` 时，`==` 默认比较的是对象身份（是否同一个对象），而不是内容。

# 5. 继承

子类继承父类的方法和属性，可以重写（override），用 `super()` 调用父类：

```python-run
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "..."

class Cat(Animal):
    def speak(self):          # 重写父类方法
        return f"{self.name}: 喵"

class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)   # 调用父类 __init__
        self.breed = breed

    def speak(self):
        return f"{self.name}: 汪"

print(Cat("咪咪").speak())            # 咪咪: 喵
print(Dog("旺财", "柯基").speak())     # 旺财: 汪
print(Dog("旺财", "柯基").breed)       # 柯基
```

# 6. 判断类型与属性

```python-run
class A:
    pass

a = A()
print(isinstance(a, A))          # True，a 是否是 A 的实例
print(type(a).__name__)          # A
print(hasattr(a, "x"))           # False，是否有属性 x
a.x = 1
print(hasattr(a, "x"))           # True
```

# 7. 易混淆点

- `self` 是约定俗成，Python 不会自动赋值，但方法第一个参数总是指向实例
- 类属性与实例属性同名时，实例属性会「遮蔽」类属性
- `__init__` 是初始化，不是真正「构造」；真正创建对象的是 `__new__`（极少需要动它）
- 忘记在方法里写 `self` 会报 `TypeError: takes N positional arguments but ...`
- `==` 默认比较身份，需要内容比较就实现 `__eq__`

```python-run
# 常见错误演示：方法漏写 self
class Bad:
    def greet():          # ❌ 少 self
        return "hi"

try:
    Bad().greet()
except TypeError as e:
    print("漏写 self 报错:", e)
```
