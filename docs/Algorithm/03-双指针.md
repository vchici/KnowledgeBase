# 双指针

> 一句话本质：双指针 = 用两个下标的移动规则代替暴力双重循环。能不能用，取决于能否证明「指针每动一步，被跳过的候选里不可能有更优解」—— 对撞靠有序性，同向靠读写分离，快慢靠速度差，窗口靠单调性。实战出场率最高的两类：**对撞**和**滑动窗口**。

## 题型总览

| 类型 | 指针怎么动 | 识别信号 | 复杂度 |
|------|-----------|---------|--------|
| 对撞指针 | 两端向中间夹逼 | 有序数组求两数、容器盛水、回文 | O(n) |
| 同向快慢指针 | 快指针探路、慢指针收结果 | 原地删除、去重、移动零 | O(n) |
| 滑动窗口（同向特例） | 右扩张、左收缩，都只前进 | **连续**子串/子数组 + 求最值 | O(n) |
| 快慢指针（速度差） | 一次走 1 步 vs 2 步 | 链表判环、找中点 | O(n) |
| 归并双指针 | 各管一个序列，比大小取小者 | 两个有序序列合并 | O(m+n) |

> 判断口诀：**有序 + 两数之和 → 对撞；原地删除/去重 → 快慢读写；子串子数组求最值 → 滑动窗口**（「连续」是窗口的硬前提，不连续就是 DP 了）。

## 对撞指针

### LC 167. 两数之和 II（有序数组）

**题目**：非递减数组 `numbers`，找两数之和等于 `target`，返回下标（从 1 开始）。

**思路**：左指针对最小值、右指针对最大值。和大了说明右数太大，`r--`；和小了说明左数太小，`l++`。每一步排除一行候选，线性收敛。

```java
class Solution {
    public int[] twoSum(int[] numbers, int target) {
        int l = 0, r = numbers.length - 1;
        while (l < r) {
            int sum = numbers[l] + numbers[r];
            if (sum == target) return new int[]{l + 1, r + 1};
            if (sum > target) r--;
            else l++;
        }
        return new int[]{-1, -1};
    }
}
```

**复杂度**：时间 O(n)，空间 O(1)。

### LC 11. 盛最多水的容器

**题目**：`height[i]` 是第 i 条竖线高度，选两条线与 x 轴围成的容器能装最多水，返回最大水量。

**思路**：从两端开始，水量 = 宽 × 矮边高度。移动较高的一边宽度只会变小、高度受矮边限制不会更好，所以**每次移动矮的一边**。

```java
class Solution {
    public int maxArea(int[] height) {
        int l = 0, r = height.length - 1, ans = 0;
        while (l < r) {
            ans = Math.max(ans, Math.min(height[l], height[r]) * (r - l));
            if (height[l] < height[r]) l++;
            else r--;
        }
        return ans;
    }
}
```

**复杂度**：时间 O(n)，空间 O(1)。

### LC 15. 三数之和（排序 + 对撞 + 双层去重）

**题目**：整数数组 `nums`，找出所有不重复的三元组 `[nums[i], nums[j], nums[k]]` 使三数之和为 0。

**思路**：先排序。固定最小数 `nums[i]`，右侧区间 `[i+1, n-1]` 变成「有序数组找两数之和 = -nums[i]」——正是 LC 167 的对撞。**本题难点全在去重**：两层各去一次。

```java
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        Arrays.sort(nums);                                 // 去重和收缩都建立在有序上
        List<List<Integer>> ans = new ArrayList<>();
        for (int i = 0; i < nums.length - 2; i++) {
            if (nums[i] > 0) break;                        // 最小数 > 0，不可能凑出 0
            if (i > 0 && nums[i] == nums[i - 1]) continue; // 去重①：跳过重复的固定数
            int l = i + 1, r = nums.length - 1;
            while (l < r) {
                int sum = nums[i] + nums[l] + nums[r];
                if (sum < 0) l++;
                else if (sum > 0) r--;
                else {
                    ans.add(List.of(nums[i], nums[l], nums[r]));
                    while (l < r && nums[l] == nums[l + 1]) l++;   // 去重②：跳过重复左
                    while (l < r && nums[r] == nums[r - 1]) r--;   // 去重③：跳过重复右
                    l++; r--;                              // 落到下一个新值上
                }
            }
        }
        return ans;
    }
}
```

**复杂度**：时间 O(n²)（排序 O(n log n) + 外层 n × 对撞 n），空间 O(1)（不计答案）。

> 面试口径：去重②③必须在**找到一个解之后**做，而不是跳循环前——否则会漏掉 `[0,0,0]` 这种解。`nums[i] > 0` 提前剪枝是加分项。

## 同向快慢指针（读写分离）

### LC 27. 移除元素

**题目**：原地删除数组中所有值等于 `val` 的元素，返回新长度，前 k 个元素是保留结果。

**思路**：`slow` 指向「下一个保留值该放的位置」，`fast` 扫描全数组。不等于 `val` 才写入并前进 slow —— 读和写分离，一遍扫完。

```java
class Solution {
    public int removeElement(int[] nums, int val) {
        int slow = 0;
        for (int fast = 0; fast < nums.length; fast++) {
            if (nums[fast] != val) {
                nums[slow++] = nums[fast];
            }
        }
        return slow;
    }
}
```

**复杂度**：时间 O(n)，空间 O(1)。

### LC 26. 删除有序数组中的重复项

**题目**：非严格递增数组原地去重，返回唯一元素个数 k，前 k 位有序不重复。

**思路**：和 LC 27 同骨架，判断条件从「不等于 val」换成「不等于 `nums[slow]`（慢指针代表的最后一个保留值）」。

```java
class Solution {
    public int removeDuplicates(int[] nums) {
        int slow = 0;
        for (int fast = 1; fast < nums.length; fast++) {
            if (nums[fast] != nums[slow]) {   // 遇到新值
                nums[++slow] = nums[fast];    // 写到保留区末尾的下一格
            }
        }
        return slow + 1;                      // slow 是下标，个数要 +1
    }
}
```

### LC 283. 移动零

**题目**：把数组所有 0 移到末尾，保持非零元素相对顺序，原地。

**思路**：前半程就是 LC 27（val = 0 的读写分离），多一步尾部补 0。

```java
class Solution {
    public void moveZeroes(int[] nums) {
        int slow = 0;
        for (int fast = 0; fast < nums.length; fast++) {
            if (nums[fast] != 0) nums[slow++] = nums[fast];   // 非 0 前写
        }
        while (slow < nums.length) nums[slow++] = 0;          // 保留区之后补 0
    }
}
```

> 三题一个模板：**fast 负责「读和筛选」，slow 负责「写」**；26 返回 `slow + 1`（下标），27/283 返回 `slow`（个数/位置）——边界差一，是最常见笔误。

## 滑动窗口（同向特例，实战高频）

> 一句话本质：右指针扩张、左指针收缩，**两个指针都只前进不回头**——每个元素最多进出窗口各一次，所以内层 while 不破坏 O(n)。识别信号：**连续**子串/子数组 + 求最值。

两个镜像方向，同一个骨架：

- **求最短窗口**（LC 209）：不满足就扩，一满足就缩
- **求最长窗口**（LC 3）：不满足才缩，能扩就扩

### LC 209. 长度最小的子数组

**题目**：正整数数组 `nums` 和正整数 `target`，找和 ≥ target 的**最短**连续子数组长度，不存在返回 0。

**思路**：窗口和 `sum`。右扩加数；一旦 `sum >= target` 就尽量缩左边——正数保证缩完还可能仍满足，所以每次缩都更新最短值。

### LC 3. 无重复字符的最长子串

### LC 438. 找到字符串中所有字母异位词（定长窗口）

**题目**：字符串 `s` 和 `p`，找 `p` 的所有异位词子串的起始下标。

**思路**：异位词 = 长度相同 + 每个字母计数相同 → **定长窗口**。窗口每滑动一步只做「右端进一个、左端出一个」，比较两个计数数组。

```java
class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> ans = new ArrayList<>();
        int[] need = new int[26], win = new int[26];
        for (char c : p.toCharArray()) need[c - 'a']++;
        int m = p.length();
        for (int r = 0; r < s.length(); r++) {
            win[s.charAt(r) - 'a']++;                     // 右端进窗
            if (r >= m) win[s.charAt(r - m) - 'a']--;     // 左端出窗，保持定长 m
            if (r >= m - 1 && Arrays.equals(need, win)) ans.add(r - m + 1);
        }
        return ans;
    }
}
```

**复杂度**：时间 O(26n)，空间 O(26)。

### LC 76. 最小覆盖子串（不定长窗口通用模板）

**题目**：字符串 `s` 和 `t`，找 `s` 中包含 `t` **全部字符**（含重复）的最短子串，不存在返回 ""。

**思路**：不定长窗口的完全体。`need` 记 t 的需求，`valid` 记「已凑够需求的字符种类数」。右扩凑需求；`valid` 齐了就左缩逼近最短。**209 是它的简化版**（需求只有一种：和 ≥ target）。

```java
class Solution {
    public String minWindow(String s, String t) {
        int[] need = new int[128], win = new int[128];
        for (char c : t.toCharArray()) need[c]++;
        int needKinds = 0;                        // t 中的字符种类数
        for (int x : need) if (x > 0) needKinds++;

        int l = 0, valid = 0, minLen = Integer.MAX_VALUE, start = 0;
        for (int r = 0; r < s.length(); r++) {
            char c = s.charAt(r);
            if (need[c] > 0) {
                win[c]++;
                if (win[c] == need[c]) valid++;   // 恰好凑够一种 → valid++
            }
            while (valid == needKinds) {          // 全覆盖 → 收缩逼近最短
                if (r - l + 1 < minLen) { minLen = r - l + 1; start = l; }
                char d = s.charAt(l++);
                if (need[d] > 0) {
                    if (win[d] == need[d]) valid--;   // 移走的是「刚好够」的 → 不再覆盖
                    win[d]--;
                }
            }
        }
        return minLen == Integer.MAX_VALUE ? "" : s.substring(start, start + minLen);
    }
}
```

**复杂度**：时间 O(n)，空间 O(128)。

> 面试口径：`valid` 用**种类数**而不是字符总数比较，避免「A 有 3 个但只要 2 个」的误判；`win[c] == need[c]` 恰好相等才加减 valid，是模板最容易写错的两处。76 会了，209/438 都能退化出来。

## 快慢指针（速度差）

### LC 141. 环形链表

**题目**：判断链表是否有环。

**思路**：慢指针一次 1 步、快指针一次 2 步。有环则快指针必然在环内追上慢指针；无环则快指针先到 `null`。

```java
public class Solution {
    public boolean hasCycle(ListNode head) {
        ListNode slow = head, fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
            if (slow == fast) return true;
        }
        return false;
    }
}
```

**复杂度**：时间 O(n)，空间 O(1)。

### LC 142. 环形链表 II（追问标配：返回入环口）

**题目**：判断是否有环，有则返回入环的第一个节点，无环返回 null。

**思路**：141 判相遇是第一步；相遇后，**头指针和慢指针同速前进，再相遇处即入环口**。

```java
public class Solution {
    public ListNode detectCycle(ListNode head) {
        ListNode slow = head, fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
            if (slow == fast) {                 // 相遇：进入第二阶段
                ListNode p = head;
                while (p != slow) { p = p.next; slow = slow.next; }
                return p;                       // 再相遇即入环口
            }
        }
        return null;
    }
}
```

**复杂度**：时间 O(n)，空间 O(1)。

> 数学口径：设头到入环口距离 a、入环口到相遇点 b。fast 路程 = 2×slow 路程 → `a+b+n·环长 = 2(a+b)` → `a = n·环长 - b`，即「头到入环口」与「相遇点继续走到入环口」同余——所以两个同速指针必然在入环口相遇。

## 归并双指针

### LC 88. 合并两个有序数组（原地，从后往前）

**题目**：`nums1` 长度 m+n，前 m 个有序；`nums2` 长 n 有序。原地合并进 `nums1`。

**思路**：正向归并会覆盖 `nums1` 还没比较的元素；**从后往前填**——`nums1` 的空位恰好在尾部，谁大谁占尾部空位。

```java
class Solution {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        int i = m - 1, j = n - 1, p = m + n - 1;    // 三个指针都从尾部出发
        while (j >= 0) {                             // nums2 耗尽即结束
            if (i >= 0 && nums1[i] > nums2[j]) nums1[p--] = nums1[i--];
            else nums1[p--] = nums2[j--];
        }
    }
}
```

**复杂度**：时间 O(m+n)，空间 O(1)。

> 口诀：**「谁大谁去尾部，j 先空则停」**。循环条件是 `j >= 0` 而不是 `i >= 0`——nums2 没填完就必须继续，nums1 剩下的本来就在正确位置上。
