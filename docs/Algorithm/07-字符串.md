# 字符串（灵茶山艾府题单精选）

> 一句话本质：拿到字符串题先问「**子串还是子序列**」。子串连续，靠 KMP / Z 函数 / Manacher / 哈希把 O(n²) 匹配降到 O(n)；子序列不连续，靠子序列自动机（一个 next 数组）或 DP。
>
> 原始题单：[灵神字符串题单（KMP/Z函数/Manacher/字符串哈希/AC自动机/后缀数组/子序列自动机）](https://leetcode.cn/circle/discuss/SJFwQI/)

## 方法论四条

1. **KMP 的灵魂是 border**：border = 既是真前缀又是真后缀的字符串。π[i] = 前缀 p[:i+1] 的最长 border 长度。失配时模式串右移到 border 重合处，跳过必然失败的比较——已匹配部分的信息全部复用
2. **Z 函数与 Manacher 是同一招**：i 落在已算出的匹配窗口内就「继承镜像信息 + 少量暴力扩展」，均摊 O(n)。学的时候对着比较
3. **字符串哈希 = 把子串压成 O(1) 可比的数字**：前缀哈希 + 幂次数组，任意子串 O(1) 取哈希；防碰撞用双模或验原串
4. **子序列自动机没有名字那么吓人**：nxt[i][c] = i 右侧最近字符 c 的下标，预处理从右往左扫一遍

## 经典题解（题目 + Java 解答）

### 28 找出字符串中第一个匹配项的下标（KMP 模板）

题目：返回 needle 在 haystack 中首次出现的下标，没有返回 −1。

思路：两步都是「失配跳 π[j−1] 再比」。①对 p 自匹配构建 π：p[:i] 的 border 已在前面算过，p[i] 对不上就回跳；②拿 p 匹配 s：在 s[i] 失配时，已匹配的 p[:j] 与 s 对齐段相同，p[:j] 的最长 border 天然已对齐，j 跳到 π[j−1] 即可。

```java
public int strStr(String ss, String pp) {
    char[] s = ss.toCharArray(), p = pp.toCharArray();
    int n = s.length, m = p.length;
    if (m == 0) return 0;
    int[] pi = new int[m];                       // pi[i]：p[:i+1] 的最长 border 长度
    for (int i = 1, c = 0; i < m; i++) {         // 自匹配构建 π
        char x = p[i];
        while (c > 0 && p[c] != x) c = pi[c - 1];
        if (p[c] == x) c++;
        pi[i] = c;
    }
    for (int i = 0, j = 0; i < n; i++) {         // 匹配文本串
        char x = s[i];
        while (j > 0 && p[j] != x) j = pi[j - 1];
        if (p[j] == x) j++;
        if (j == m) return i - m + 1;
    }
    return -1;
}
```

复杂度：O(n+m) 时间——j 每轮最多 +1，回跳总量不超过 +1 总量，均摊 O(n)；O(m) 空间。

### 459 重复的子字符串（KMP 判周期）

题目：s 能否由一个子串重复多次构成。

思路：结论题。π[n−1] = 最长 border 长度，则 d = n − π[n−1] 就是最小周期；d 能整除 n 当且仅当答案为 true。例：s = ababab，π[5] = 4，d = 2，6 % 2 == 0 → true。

```java
public boolean repeatedSubstringPattern(String s) {
    char[] a = s.toCharArray();
    int n = a.length;
    int[] pi = new int[n];
    for (int i = 1, c = 0; i < n; i++) {
        char x = a[i];
        while (c > 0 && a[c] != x) c = pi[c - 1];
        if (a[c] == x) c++;
        pi[i] = c;
    }
    return pi[n - 1] > 0 && n % (n - pi[n - 1]) == 0;
}
```

为什么成立：border 意味着开头 d 个字符与结尾 d 个字符逐位相同，把 s 循环左移 d 位得到 s 自己，说明 s 是长度 d 的周期串；d 整除 n 时周期完整铺满整串。

复杂度：O(n) 时间，O(n) 空间。

### 1392 最长快乐前缀（border 直接应用）

题目：找既是非空前缀又是非空后缀的最长子串（快乐前缀）。

思路：快乐前缀就是 border 的定义本身，答案 = π[n−1]，直接返回 `s.substring(0, pi[n-1])`。不存在时 π[n−1] = 0 返回空串。

```java
public String longestPrefix(String s) {
    char[] a = s.toCharArray();
    int n = a.length;
    int[] pi = new int[n];
    for (int i = 1, c = 0; i < n; i++) {
        char x = a[i];
        while (c > 0 && a[c] != x) c = pi[c - 1];
        if (a[c] == x) c++;
        pi[i] = c;
    }
    return s.substring(0, pi[n - 1]);
}
```

复杂度：O(n) 时间，O(n) 空间。

### 214 最短回文串（KMP + 反转拼接）

题目：在最前面加最少的字符，使 s 变成回文。

思路：本质是找 s 的**最长回文前缀**，剩下部分反转后拼到前面。对 t = s + '#' + rev(s) 求 π，π 末位 = s 前缀与 rev(s) 前缀的最长匹配 = s 的最长回文前缀长度。'#' 分隔防止 border 跨过边界把长度算超。

```java
public String shortestPalindrome(String s) {
    char[] a = s.toCharArray();
    int n = a.length;
    if (n == 0) return s;
    char[] t = new char[2 * n + 1];              // t = s + '#' + reverse(s)
    for (int i = 0; i < n; i++) t[i] = a[i];
    t[n] = '#';
    for (int i = 0; i < n; i++) t[2 * n - i] = a[i];
    int m = t.length;
    int[] pi = new int[m];
    for (int i = 1, c = 0; i < m; i++) {
        char x = t[i];
        while (c > 0 && t[c] != x) c = pi[c - 1];
        if (t[c] == x) c++;
        pi[i] = c;
    }
    int k = pi[m - 1];                           // s 的最长回文前缀长度
    return new StringBuilder(s.substring(k)).reverse() + s;
}
```

为什么 π 末位就是答案：t 的 border 同时是 s 的后缀（= rev(s) 的前缀）与 s 的前缀，s 的某个前缀等于 rev(s) 的同长前缀 ⟺ 该前缀是回文。

复杂度：O(n) 时间，O(n) 空间。

### 5 最长回文子串（Manacher 模板）

题目：返回 s 中最长的回文子串。

思路：每个字符间插 '#'、两端放 '^' '$' 守边界，奇偶回文统一处理。p[i] = 以 t[i] 为中心的最大回文半径，**恰好等于原串回文长度**。继承：i 在当前最右回文 [c, rm] 内时，镜像 j = 2c−i 的结果可用，p[i] 先取 min(rm−i, p[j]) 再暴力扩展。rm 只增不减，均摊 O(n)。

```java
public String longestPalindrome(String S) {
    char[] s = S.toCharArray();
    int n = s.length;
    char[] t = new char[2 * n + 3];              // ^ # a # b # a # $ 这种形状
    t[0] = '^'; t[1] = '#'; t[t.length - 1] = '$';
    for (int i = 0; i < n; i++) {
        t[2 + 2 * i] = s[i];
        t[3 + 2 * i] = '#';
    }
    int[] p = new int[t.length];
    int c = 0, rm = 0;                           // 当前最右回文的中心与右边界
    for (int i = 1; i < t.length - 1; i++) {
        p[i] = i < rm ? Math.min(rm - i, p[2 * c - i]) : 0;   // 继承
        while (t[i - p[i] - 1] == t[i + p[i] + 1]) p[i]++;    // 暴力扩展
        if (i + p[i] > rm) { c = i; rm = i + p[i]; }
    }
    int best = 0, center = 0;
    for (int i = 1; i < t.length - 1; i++) {
        if (p[i] > best) { best = p[i]; center = i; }
    }
    return S.substring((center - 1 - best) / 2, (center - 1 + best) / 2);
}
```

坐标换算：原字符 s[i] 固定在 t[2+2i]，回文区间 [center−best, center+best] 两端必是 '#'，往内缩一格换算得起点 (center−1−best)/2。

复杂度：O(n) 时间，O(n) 空间。

### 647 回文子串（Manacher 一鱼两吃）

题目：统计回文子串个数（位置不同就算不同）。

思路：同一套 Manacher，统计每个中心的贡献：中心是字符（p 奇数）贡献 (p+1)/2 个回文，中心是 '#'（p 偶数）贡献 p/2 = (p+1)/2 向下取整，统一写 `ans += (p[i] + 1) / 2`。验证：p=3（aba）贡献 2 个（a 中那个字符、aba），p=2（aa）贡献 1 个（aa）。

```java
public int countSubstrings(String S) {
    char[] s = S.toCharArray();
    int n = s.length;
    char[] t = new char[2 * n + 3];
    t[0] = '^'; t[1] = '#'; t[t.length - 1] = '$';
    for (int i = 0; i < n; i++) {
        t[2 + 2 * i] = s[i];
        t[3 + 2 * i] = '#';
    }
    int[] p = new int[t.length];
    int c = 0, rm = 0, ans = 0;
    for (int i = 1; i < t.length - 1; i++) {
        p[i] = i < rm ? Math.min(rm - i, p[2 * c - i]) : 0;
        while (t[i - p[i] - 1] == t[i + p[i] + 1]) p[i]++;
        if (i + p[i] > rm) { c = i; rm = i + p[i]; }
        ans += (p[i] + 1) / 2;
    }
    return ans;
}
```

简单版：中心扩展 O(n²) 也能过这题，面试可先讲它再提 Manacher。

复杂度：O(n) 时间，O(n) 空间。

### 2223 构造字符串的总得分和（Z 函数模板）

题目：从空串开始每次在前面加一个字符得到 s，s_i 得分为长度 i 的串与 s 的最长公共前缀长度，求所有得分和。

思路：得分 = 各前缀与 s 的 LCP = z 数组之和。z[i] = s[i:] 与 s 的 LCP 长度，z[0] = n。维护 z-box [l, r)：i 在盒内先继承 min(z[i−l], r−i)，再暴力扩展；r 只增不减，均摊 O(n)。

```java
public long sumScores(String S) {
    char[] s = S.toCharArray();
    int n = s.length;
    int[] z = new int[n];
    z[0] = n;
    int l = 0, r = 0;                            // z-box：s[l..r) 与 s 的前缀完全相同
    for (int i = 1; i < n; i++) {
        if (i < r) z[i] = Math.min(r - i, z[i - l]);   // 继承
        while (i + z[i] < n && s[z[i]] == s[i + z[i]]) z[i]++;   // 暴力扩展
        if (i + z[i] > r) { l = i; r = i + z[i]; }
    }
    long ans = 0;
    for (int v : z) ans += v;
    return ans;
}
```

Z 函数做匹配的套路：拼 t = pattern + s，z[m+i] ≥ m（m 是 pattern 长度）即 s[i] 起匹配成功。所以 28、459 等匹配题 Z 函数也能做，二选一即可。

复杂度：O(n) 时间，O(n) 空间。

### 187 重复的 DNA 序列（滚动哈希入门）

题目：找出所有在 s 中出现超过一次的长度为 10 的子串。

思路：定长窗口滚动更新编码，O(1) 每步。4 种碱基用 2 bit 编码（A=00 C=01 G=10 T=11），长度 10 → 20 bit，一个 int 装下，用计数 Map 过滤「恰好第 2 次出现」的编码避免重复输出。

```java
public List<String> findRepeatedDnaSequences(String s) {
    List<String> ans = new ArrayList<>();
    if (s.length() < 10) return ans;
    Map<Character, Integer> code = Map.of('A', 0, 'C', 1, 'G', 2, 'T', 3);
    Map<Integer, Integer> seen = new HashMap<>();
    int key = 0;
    for (int i = 0; i < s.length(); i++) {
        key = (key << 2 | code.get(s.charAt(i))) & ((1 << 20) - 1);   // 滚动编码
        if (i >= 9 && seen.merge(key, 1, Integer::sum) == 2) {
            ans.add(s.substring(i - 9, i + 1));
        }
    }
    return ans;
}
```

复杂度：O(n) 时间，O(n) 空间。

### 1044 最长重复子串（哈希 + 二分）

题目：找出出现 ≥ 2 次的最长子串，可重叠，没有返回空串。

思路：长度有单调性——长 L 有重复则所有更短长度都有 → **二分长度**，每个长度用子串哈希 O(n) 判重。子串哈希公式：hash(s[l..r)) = h[r] − h[l]·B^(r−l)。

```java
public String longestDupSubstring(String s) {
    char[] a = s.toCharArray();
    int n = a.length;
    final long B = 131, MOD = 1_070_777_777;     // B 取大于字符集的数，MOD 取质数
    long[] h = new long[n + 1], pw = new long[n + 1];
    pw[0] = 1;
    for (int i = 0; i < n; i++) {                // h[i]：前 i 个字符的哈希
        h[i + 1] = (h[i] * B + a[i]) % MOD;
        pw[i + 1] = pw[i] * B % MOD;
    }
    int lo = 1, hi = n - 1, start = -1, len = 0;
    while (lo <= hi) {
        int mid = (lo + hi) >>> 1;
        int pos = check(a, h, pw, mid, B, MOD);
        if (pos >= 0) { start = pos; len = mid; lo = mid + 1; }
        else hi = mid - 1;
    }
    return start < 0 ? "" : s.substring(start, start + len);
}

private int check(char[] a, long[] h, long[] pw, int len, long B, long MOD) {
    Map<Long, Integer> seen = new HashMap<>();
    for (int i = 0; i + len <= a.length; i++) {
        long hash = (h[i + len] - h[i] * pw[len] % MOD + MOD) % MOD;
        Integer prev = seen.putIfAbsent(hash, i);
        if (prev != null) return prev;           // 稳妥起见可再比对原串防碰撞
    }
    return -1;
}
```

复杂度：O(n log n) 时间，O(n) 空间。

### 792 匹配子序列的单词数（子序列自动机模板）

题目：words 里有多少个是 s 的子序列。

思路：预处理 nxt[i][c] = 位置 ≥ i 中最近的字符 c 下标，从右往左扫一遍（第 i 行 = 第 i+1 行拷贝后改一个值）。匹配单词时从 pos=0 起逐字符跳表，跳到 n 表示找不到即失败。把每个单词的 O(n) 暴力扫描变成 O(单词长度) 跳表。

```java
public int numMatchingSubsequences(String s, String[] words) {
    char[] a = s.toCharArray();
    int n = a.length;
    int[][] nxt = new int[n + 1][26];            // nxt[i][c]：≥ i 中最近字符 c 的下标
    Arrays.fill(nxt[n], n);                      // n 表示不存在
    for (int i = n - 1; i >= 0; i--) {
        nxt[i] = nxt[i + 1].clone();
        nxt[i][a[i] - 'a'] = i;
    }
    int ans = 0;
    for (String w : words) {
        int pos = 0;
        boolean ok = true;
        for (char ch : w.toCharArray()) {
            pos = nxt[pos][ch - 'a'];
            if (pos == n) { ok = false; break; }
            pos++;                               // 从该字符后面继续找下一个
        }
        if (ok) ans++;
    }
    return ans;
}
```

复杂度：预处理 O(26n)，匹配 Σ|w|；空间 O(26n)。

```java
while (i != -1) {
```

**用法二：首次出现位置当字符「身份」**（205 同构字符串、890 查找和替换模式）

```java
public boolean isIsomorphic(String s, String t) {
    for (int i = 0; i < s.length(); i++) {
        if (s.indexOf(s.charAt(i)) != t.indexOf(t.charAt(i))) return false;
    }
    return true;
}
```

原理：s[i] 和 t[i] 若是同一映射角色，两者在各自串里首次出现的位置必然相同（egg/add：位置 1 和 2 的 g、d 首现位置都是 1）。一次 indexOf 代替一个 HashMap，O(n²) 但代码极短，n 小时首选。

```java
    return s.length() - s.lastIndexOf(" ") - 1;   // 没空格时 lastIndexOf 返回 -1，公式照样成立
}
```

### split 的正则语义

```java
"a.b.c".split(".")          // 得空数组！. 是正则元字符，每个字符都被切开
"a.b.c".split("\\.")        // ✅ ["a", "b", "c"]；|、[ 同理要转义
"a,,b,,".split(",")         // ["a", "", "b"]——尾部空串默认丢弃
"a,,b,,".split(",", -1)     // ["a", "", "b", "", ""]——limit=-1 保留尾部
"a  b".split("\\s+")        // 多空格用 \s+；开头有空格会产生空串，配合 trim()
```
