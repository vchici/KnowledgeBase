# 动态规划（灵茶山艾府题单精选）

> 一句话本质：DP 就是「当前怎么做，取决于子问题怎么算」。灵神方法论：想「**最后一步发生了什么**」→ 得到子问题 → 定义状态 → 写转移。先写记忆化搜索，再 1:1 翻译成递推。
>
> 原始题单：[灵神 DP 题单（入门/背包/划分/状态机/区间/状压/数位/树形/优化）](https://leetcode.cn/circle/discuss/tXLS3i/)

## 方法论四条

1. **思考最后一步**：最后一步选了什么 / 走到了哪，就能拆出子问题
2. **记忆化搜索是新手村神器**：直接按题意递归，加个 cache 就是 DP；熟练后直接写递推
3. **1:1 翻译**：递归改递推，DP 数组大小看参数范围——i 最小 −1、最大 n−1，就开 n+1
4. **两大类转移**：「选或不选」（0-1 背包、打家劫舍）和「枚举选哪个」（LIS、划分、爬楼梯）

返回值口诀：状态定义是「**以 i 结尾**」→ 答案是 `max(f)`；「**前 i 个**」→ 答案是 `f[n]`。

## 经典题解（题目 + Java 解答）

### 70 爬楼梯

题目：每次爬 1 或 2 阶，问爬到 n 阶有多少种方法。

思路：最后一步爬 1 阶还是 2 阶 → f[i] = f[i−1] + f[i−2]。

```java
public int climbStairs(int n) {
    int[] f = new int[n + 1];   // f[i]：走到第 i 阶的方法数
    f[0] = 1;
    f[1] = 1;
    for (int i = 2; i <= n; i++) {
        f[i] = f[i - 1] + f[i - 2];
    }
    return f[n];
}
```

**f[i] 是什么**：走到第 i 阶的方法数。最后一步要么从 i−1 阶爬 1 阶（f[i−1] 种），要么从 i−2 阶爬 2 阶（f[i−2] 种），两类互不重叠，按加法原理相加。f[0] = 1 是边界：站在地面算 1 种方式。

拿 n = 5 走一遍：

| i | f[i−2] | f[i−1] | f[i] |
|---|--------|--------|------|
| 2 | 1 | 1 | 2 |
| 3 | 1 | 2 | 3 |
| 4 | 2 | 3 | 5 |
| 5 | 3 | 5 | 8 |

返回 f[5] = 8，即爬到 5 阶共 8 种方法。

复杂度：O(n) 时间，O(n) 空间。

### 198 打家劫舍

题目：数组是每间房的现金，不能偷相邻两间，求最大金额。

思路：枚举最后一间偷或不偷，f[i] = max(f[i−1], f[i−2] + nums[i])。

```java
public int rob(int[] nums) {
    int n = nums.length;
    if (n == 1) return nums[0];
    int[] f = new int[n];   // f[i]：考虑下标 0..i 这些房间的最大金额
    f[0] = nums[0];
    f[1] = Math.max(nums[0], nums[1]);
    for (int i = 2; i < n; i++) {
        f[i] = Math.max(f[i - 1], f[i - 2] + nums[i]);
    }
    return f[n - 1];
}
```

f[i] 的两个来源：不偷当前间 = f[i−1]，偷当前间 = f[i−2] + nums[i]（i−1 间必须没偷）。

复杂度：O(n) 时间，O(n) 空间。

### 213 打家劫舍 II

题目：同上，但房子排成环形（首尾相邻）。

思路：环形拆两条链——不偷第一间、不偷最后一间，分别用 198 的逻辑，取 max。

```java
public int rob(int[] nums) {
    int n = nums.length;
    if (n == 1) return nums[0];
    return Math.max(robRange(nums, 1, n), robRange(nums, 0, n - 1));
}

private int robRange(int[] nums, int start, int end) {
    int m = end - start;
    if (m == 1) return nums[start];
    int[] f = new int[m];
    f[0] = nums[start];
    f[1] = Math.max(nums[start], nums[start + 1]);
    for (int i = 2; i < m; i++) {
        f[i] = Math.max(f[i - 1], f[i - 2] + nums[start + i]);
    }
    return f[m - 1];
}
```

复杂度：O(n) 时间，O(n) 空间。

### 53 最大子数组和

题目：找一个和最大的连续子数组，返回其和。

思路：f[i] = 以 a[i] 结尾的最大和，拼上左边 f[i] = f[i−1] + a[i]，不拼 f[i] = a[i]，合起来 f[i] = max(f[i−1], 0) + a[i]；答案 max(f)。

```java
public int maxSubArray(int[] nums) {
    int[] f = new int[nums.length];   // f[i]：以 nums[i] 结尾的最大子数组和
    f[0] = nums[0];
    int ans = nums[0];
    for (int i = 1; i < nums.length; i++) {
        f[i] = Math.max(f[i - 1], 0) + nums[i];
        ans = Math.max(ans, f[i]);
    }
    return ans;
}
```

复杂度：O(n) 时间，O(n) 空间（ans = max(f)，符合「以 i 结尾 → 返回 max(f)」口诀）。

### 152 乘积最大子数组

题目：找一个乘积最大的连续子数组，数组含负数和 0。

思路：负负得正，所以同时维护「以 i 结尾的最大乘积」和「最小乘积」，转移时三个来源取 max/min。

```java
public int maxProduct(int[] nums) {
    int n = nums.length;
    int[] mx = new int[n];   // 以 nums[i] 结尾的最大乘积
    int[] mn = new int[n];   // 以 nums[i] 结尾的最小乘积
    mx[0] = mn[0] = nums[0];
    int ans = nums[0];
    for (int i = 1; i < n; i++) {
        mx[i] = Math.max(nums[i], Math.max(mx[i - 1] * nums[i], mn[i - 1] * nums[i]));
        mn[i] = Math.min(nums[i], Math.min(mx[i - 1] * nums[i], mn[i - 1] * nums[i]));
        ans = Math.max(ans, mx[i]);
    }
    return ans;
}
```

复杂度：O(n) 时间，O(n) 空间。

### 416 分割等和子集

题目：能否把数组分成两个子集，使两个子集的和相等。

思路：转化成 0-1 背包——能否恰好装满 sum/2，布尔 DP，一维优化倒序遍历。

```java
public boolean canPartition(int[] nums) {
    int s = 0;
    for (int x : nums) s += x;
    if (s % 2 == 1) return false;
    boolean[] f = new boolean[s / 2 + 1];
    f[0] = true;
    for (int x : nums) {
        for (int c = s / 2; c >= x; c--) {   // 倒序，防止同一物品被选两次
            f[c] |= f[c - x];
        }
    }
    return f[s / 2];
}
```

f[c] 的含义：用已遍历过的数字，**能否恰好凑出和为 c**。f[0] = true 是边界（一个都不选凑出 0）；转移 f[c] |= f[c − x] 表示凑出 c 要么不选 x（看 f[c]），要么选 x（看 f[c − x]）；答案 f[s/2]：能凑出一半，剩下自然是另一半。

**为什么倒序**：转移要求 f[c − x] 是「没考虑过 x」的旧值。倒序先算大的 c，算 f[c] 时小下标还没被本轮更新，x 最多用一次。正序则相反：算 f[6] 时 f[3] 可能是本轮刚算出的、已经含 x 的新值，等于 x 被用了两次。例：nums = [3]，正序会错算出 f[6] = true（3 + 3），倒序正确得 f[3] = true、f[6] = false。完全背包正序能重复选，原理正好反过来。

复杂度：O(n·sum) 时间，O(sum) 空间。

### 494 目标和

题目：给每个数加 +/− 号，使表达式结果等于 target，求方案数。

思路：设正数子集和为 p，负数子集和为 s−p，p−(s−p)=target → p=(s+target)/2，转化成「选子集和为 (s+target)/2 的方案数」。

```java
public int findTargetSumWays(int[] nums, int target) {
    int s = 0;
    for (int x : nums) s += x;
    s += target;
    if (s < 0 || s % 2 == 1) return 0;
    int cap = s / 2;
    int[] f = new int[cap + 1];
    f[0] = 1;
    for (int x : nums) {
        for (int c = cap; c >= x; c--) {   // 0-1 背包，倒序
            f[c] += f[c - x];
        }
    }
    return f[cap];
}
```

复杂度：O(n·cap) 时间，O(cap) 空间。

### 322 零钱兑换

题目：硬币可重复用，凑出 amount 的最少硬币数，凑不出返回 −1。

思路：完全背包求最少，f[c] = min(f[c], f[c−coin] + 1)。

```java
public int coinChange(int[] coins, int amount) {
    int[] f = new int[amount + 1];
    Arrays.fill(f, Integer.MAX_VALUE / 2);   // 表示凑不出，除 2 防溢出
    f[0] = 0;
    for (int coin : coins) {
        for (int c = coin; c <= amount; c++) {
            f[c] = Math.min(f[c], f[c - coin] + 1);
        }
    }
    return f[amount] < Integer.MAX_VALUE / 2 ? f[amount] : -1;
}
```

复杂度：O(n·amount) 时间，O(amount) 空间。

### 518 零钱兑换 II

题目：硬币可重复用，求凑出 amount 的组合数。

思路：完全背包求方案数，f[c] += f[c−coin]。**必须先物品后容量**（保证组合不计顺序），且正序遍历。

```java
public int change(int amount, int[] coins) {
    int[] f = new int[amount + 1];
    f[0] = 1;
    for (int coin : coins) {                 // 先物品
        for (int c = coin; c <= amount; c++) {   // 后容量，正序
            f[c] += f[c - coin];
        }
    }
    return f[amount];
}
```

复杂度：O(n·amount) 时间，O(amount) 空间。

### 1143 最长公共子序列

题目：求两个字符串的最长公共子序列（不要求连续）的长度。

思路：f[i][j] 表示 s[:i] 与 t[:j] 的答案；末尾字符相等则 f[i−1][j−1] + 1，否则 max(f[i−1][j], f[i][j−1])。

```java
public int longestCommonSubsequence(String s, String t) {
    char[] a = s.toCharArray(), b = t.toCharArray();
    int[][] f = new int[a.length + 1][b.length + 1];
    for (int i = 1; i <= a.length; i++) {
        for (int j = 1; j <= b.length; j++) {
            if (a[i - 1] == b[j - 1]) f[i][j] = f[i - 1][j - 1] + 1;
            else f[i][j] = Math.max(f[i - 1][j], f[i][j - 1]);
        }
    }
    return f[a.length][b.length];
}
```

复杂度：O(mn) 时间，O(mn) 空间。

### 72 编辑距离

题目：把 s 变成 t，最少插入、删除、替换几次。

思路：等则不用改，f[i][j] = f[i−1][j−1]；不等则在替换、删 s、删 t 三者取 min + 1。

```java
public int minDistance(String s, String t) {
    char[] a = s.toCharArray(), b = t.toCharArray();
    int[][] f = new int[a.length + 1][b.length + 1];
    for (int i = 1; i <= a.length; i++) f[i][0] = i;   // 全删
    for (int j = 1; j <= b.length; j++) f[0][j] = j;   // 全插
    for (int i = 1; i <= a.length; i++) {
        for (int j = 1; j <= b.length; j++) {
            if (a[i - 1] == b[j - 1]) f[i][j] = f[i - 1][j - 1];
            else f[i][j] = Math.min(f[i - 1][j - 1],
                     Math.min(f[i - 1][j], f[i][j - 1])) + 1;
        }
    }
    return f[a.length][b.length];
}
```

复杂度：O(mn) 时间，O(mn) 空间。

### 300 最长递增子序列

题目：求严格递增子序列的最大长度。

思路：贪心数组 g，g[k] = 长度为 k+1 的 LIS 末尾最小值；每个元素二分找第一个 ≥ x 的位置替换，放不进末尾就追加。g 不一定是合法子序列，但长度对。

```java
public int lengthOfLIS(int[] nums) {
    int[] g = new int[nums.length];
    int len = 0;
    for (int x : nums) {
        int l = 0, r = len;   // 二分找第一个 >= x 的位置
        while (l < r) {
            int mid = (l + r) >>> 1;
            if (g[mid] < x) l = mid + 1;
            else r = mid;
        }
        g[l] = x;
        if (l == len) len++;
    }
    return len;
}
```

复杂度：O(n log n) 时间，O(n) 空间。

### 139 单词拆分

题目：s 能否由词典里的单词拼接而成（可重复用）。

思路：划分型 DP，f[i] = 前缀 s[:i] 能否拼出，枚举最后一个单词的起点 j：f[j] 为真且 s[j:i] 在词典。

```java
public boolean wordBreak(String s, List<String> wordDict) {
    Set<String> set = new HashSet<>(wordDict);
    boolean[] f = new boolean[s.length() + 1];
    f[0] = true;
    for (int i = 1; i <= s.length(); i++) {
        for (int j = 0; j < i && !f[i]; j++) {
            f[i] = f[j] && set.contains(s.substring(j, i));
        }
    }
    return f[s.length()];
}
```

复杂度：O(n²) 时间（含 substring 开销），O(n) 空间。

### 121 买卖股票的最佳时机

题目：只能买卖一次，求最大利润。

思路：遍历时维护历史最低价，今天卖 = p − 历史最低。

```java
public int maxProfit(int[] prices) {
    int ans = 0, min = prices[0];
    for (int p : prices) {
        ans = Math.max(ans, p - min);
        min = Math.min(min, p);
    }
    return ans;
}
```

复杂度：O(n) 时间，O(1) 空间。

### 122 买卖股票的最佳时机 II

题目：可交易任意次，求最大利润。

思路：状态机 DP，f[i][持有/未持有]；持有 = max(昨天持有, 昨天未持有 − 价)，未持有 = max(昨天未持有, 昨天持有 + 价)。

```java
public int maxProfit(int[] prices) {
    int n = prices.length;
    int[][] f = new int[n][2];   // f[i][0]：第 i 天结束未持有；f[i][1]：持有
    f[0][1] = -prices[0];
    for (int i = 1; i < n; i++) {
        f[i][0] = Math.max(f[i - 1][0], f[i - 1][1] + prices[i]);
        f[i][1] = Math.max(f[i - 1][1], f[i - 1][0] - prices[i]);
    }
    return f[n - 1][0];
}
```

复杂度：O(n) 时间，O(n) 空间。

### 337 打家劫舍 III

题目：房子是一棵二叉树，不能偷直接相连的父子节点，求最大金额。

思路：树形 DP，每个节点返回两个值——偷自己的最优、不偷自己的最优；偷 = 自身 + 两个子节点的不偷值，不偷 = 两个子节点各自取 max。

```java
public int rob(TreeNode root) {
    int[] r = dfs(root);
    return Math.max(r[0], r[1]);
}

private int[] dfs(TreeNode node) {
    if (node == null) return new int[]{0, 0};
    int[] l = dfs(node.left), r = dfs(node.right);
    int rob = node.val + l[1] + r[1];                              // 偷当前
    int skip = Math.max(l[0], l[1]) + Math.max(r[0], r[1]);        // 不偷当前
    return new int[]{rob, skip};
}
```

复杂度：O(n) 时间，O(h) 空间（递归栈）。
