# Flex 与 Row、Column 的区别

> **本质**:三者都是把子组件排成一行或一列，功能上 Flex 只多一个"换行"，代价是每次测量都要跑两遍。不换行就用 Row/Column。

## 都能做什么

- `Row`:子组件横着排。
- `Column`:子组件竖着排。
- `Flex`:横排竖排都行，等于 Row/Column 的超集。

下面这些能力三者都有，不是 Flex 独有:

- 排列方向和对齐方式。
- 子组件设 `layoutWeight`，按比例分剩余空间。

Flex 独有的只有一个:**换行**(wrap)，一行放不下自动折到下一行，比如一串标签流式排列。

## 为什么 Flex 慢:测量跑两遍

```text
Row/Column:量一遍每个子组件要多大 ──► 算怎么摆 ──► 完

Flex:      量一遍每个子组件要多大 ──► 算哪些要折行、剩多少空间
           ──► 重新分配，再量一遍 ──► 完
```

第一遍只是摸底，第二遍才算数。而且不管设没设换行，Flex 都跑两遍。列表里每个 item 都用 Flex，滑动时每帧都在付双倍测量，子组件越多越明显。

## 怎么选

- 单行横排/竖排 → Row/Column，能力一样、测量减半。
- 真要折行(标签流、自动换行的按钮组) → Flex，代价认了。
