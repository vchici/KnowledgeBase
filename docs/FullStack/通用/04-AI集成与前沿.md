# AI 集成与前沿

> AI 已从「玩具」变成「生产力」。现在的前后端开发，越来越需要理解如何把大模型能力集成进业务系统。

## 一、LLM 应用基础

### Prompt 工程

- 结构化的 Prompt：角色设定 + 任务 + 上下文 + 输出约束
- 常用技巧：Few-shot 示例、CoT（思维链）、输出格式约束（JSON Schema）
- 关联笔记：[提示词工程](../../LangChain/05-提示词工程/05-提示词工程.md)

### 模型调用

- 调用范式：输入 messages（system/user/assistant）→ 输出 completion
- 关键参数：temperature（随机性）、max_tokens、stream（流式输出）
- 关联笔记：[模型调用](../../LangChain/02-模型调用/02-模型调用.md)、[消息格式](../../LangChain/04-消息格式/04-消息.md)

### 流式输出

- SSE / WebSocket 实现打字机效果，前端用 `ReadableStream` 读取
- 长响应必须流式，否则等待时间不可接受

## 二、RAG（检索增强生成）

### 为什么需要 RAG

- 大模型知识有截止时间、可能幻觉、不知道私有业务数据
- RAG = 检索相关文档 + 拼接上下文 + 生成回答

### 核心流程

```
文档入库：文档 → 切分(chunk) → 向量化(embedding) → 存入向量数据库
在线查询：用户问题 → 向量化 → 相似度检索(top-k) → 拼接 Prompt → 生成回答
```

### 工程要点

| 环节 | 关键点 |
|------|--------|
| 文档解析 | PDF/扫描件 OCR、多模态解析 |
| 切分策略 | 按语义/标题切分，重叠窗口 |
| Embedding | 选合适的模型、向量维度 |
| 混合检索 | 向量召回 + 关键词召回 + 重排（rerank） |
| 评估 | 召回率、命中率、回答准确率 |

> 关联笔记：[RAG检索增强生成](../../LangChain/RAG检索增强生成.md)、[向量数据库](../../DataBase/向量数据库.md)、[AIAgent 时代的数据库演进](../../DataBase/AIAgent 时代的数据库演进.md)

## 三、Agent 与工具调用

- **Function Calling**：模型输出结构化调用意图，应用执行真实工具
  - 关联笔记：[工具](../../LangChain/06-工具/06-工具.md)
- Agent 循环：推理 → 调用工具 → 观察结果 → 再推理
- 关键难点：工具参数校验、执行沙箱化、防幻觉、状态管理、可观测性

## 四、前后端开发者的 AI 实践

### 用 AI 提效开发

- 代码生成与补全（Copilot/Claude Code）
- 自动化测试生成、代码 Review 辅助
- 文档生成、SQL 生成、接口联调调试

### 给业务集成 AI

| 场景 | 技术栈 |
|------|--------|
| 智能客服 | RAG + 知识库 + 流式输出 |
| 内容生成 | Prompt 工程 + 工具调用 |
| 代码助手 | 沙箱执行 + 工具调用 |
| 数据分析 | NL2SQL + 图表渲染 |

## 前沿方向

- 多模态（图像/语音输入）
- 长上下文与记忆管理（短期/长期记忆分层）

- 模型微调（LoRA）与本地部署
- Agent 工作流编排（LangGraph 等）
