# 前端工程化

## 工程化解决什么问题

多人协作的代码规范、构建打包、依赖管理、质量保障、自动化发布。
**个人开发可以不做工程化，团队产品必须做。**

## 构建工具演进

| 工具 | 定位 | 特点 |
|------|------|------|
| Webpack | 传统打包器 | 生态最全、配置复杂、dev 慢 |
| Vite | 现代构建器 | 基于 ESBuild 预构建 + 原生 ESM，启动秒级 |
| Rollup | 库打包 | 产物干净，适合发布 npm 包 |
| esbuild | 极速打包器 | 用 Go 编写，构建工具的地基 |

> 现状：**应用用 Vite，库用 Rollup**。Webpack 存量项目仍需能维护。

## 必须掌握的内容

### 1. 代码规范

- ESLint：静态检查（规则、`eslint-plugin-vue`/`eslint-plugin-react`）
- Prettier：代码格式化，与 ESLint 分工（format vs lint）
- Husky + lint-staged：提交前自动检查
- 规范来源：Airbnb / Standard / 团队自定义

### 2. 模块化

- ESM（ES Module）：静态导入、tree-shaking 友好 —— 现代标准
- CJS（CommonJS）：Node 侧使用
- 包管理器：npm / pnpm（硬链接 + 内容寻址，磁盘省、快）/ yarn
- monorepo：pnpm workspace、Turborepo 管理多包项目

### 3. 代码分割与懒加载

```javascript
// 路由级代码分割（Vue 3）
const routes = [
  {
    path: '/dashboard',
    component: () => import('@/views/Dashboard.vue') // 按需加载
  }
]
```

- 为什么要做：首屏只加载必要 JS，其余按需
- 手段：动态 import、组件懒加载、图片懒加载、预加载

### 4. 测试体系

| 层级 | 工具 | 测什么 |
|------|------|--------|
| 单元测试 | Vitest / Jest | 函数、组件逻辑 |
| 组件测试 | Vue Test Utils / Testing Library | 组件渲染与交互 |
| E2E 测试 | Playwright / Cypress | 用户完整操作流程 |

### 5. 质量与体验

- TypeScript 严格模式：`strict: true`
- 浏览器兼容：Babel 转译、browserslist、polyfill
- 错误监控：Sentry 上报前端异常
- 日志与埋点：行为数据采集

### 6. CI/CD 与部署

- CI 流水线：lint → test → build → 产物上传
- 静态资源部署：CDN + 缓存策略（hash 文件名、`immutable`）
- Docker 部署前端：Nginx 托管静态文件 + 反向代理 API
