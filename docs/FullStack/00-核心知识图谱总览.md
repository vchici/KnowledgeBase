# 前后端核心知识图谱总览

> 一份贯穿前后端开发的学习地图，按「前端 / 后端 / 通用」三块组织。
> 学习核心原则：**原理 + 场景**，比「会用」更重要。
> 阅读建议：先看下面的「重点速览」，再按学习路径逐模块深入。

## 重点速览（最先看）

### 面试高频点速查

- 浏览器输入 URL 到页面渲染的全过程
- 前端性能优化手段（缓存、懒加载、防抖节流、代码分割）
- 索引为什么快？什么情况下索引失效？
- 缓存穿透/击穿/雪崩的区别与解决方案
- JWT vs Session 的区别与适用场景
- 如何保证接口幂等？如何设计一个限流系统？
- 分布式事务的常见方案（2PC/TCC/Saga/本地消息表）

### 各领域「必会」清单

| 领域 | 必须掌握 | 进阶掌握 |
|------|---------|---------|
| JS/TS | 异步编程、闭包、事件循环 | 泛型高级用法、类型体操 |
| 框架 | Hooks/Composition API、组件通信 | 虚拟 DOM、响应式原理、源码 |
| 数据库 | 索引、事务、SQL 优化 | 分库分表、主从复制、分布式事务 |
| 缓存 | 缓存穿透/击穿/雪崩 | 分布式锁、缓存一致性 |
| 系统设计 | REST API、鉴权、幂等 | 消息队列、微服务、限流降级 |
| 网络 | HTTP 生命周期、WebSocket | HTTP/2、HTTPS 握手、TCP 细节 |
| 部署 | Docker、Nginx、Linux | K8s、CI/CD、可观测性 |
| AI | Prompt 工程、LLM API 调用 | RAG、Agent、向量数据库 |

## 学习路径建议

1. **打地基（通用）**：先过一遍 HTTP/TCP 网络协议、Git 协作 —— 一切业务都跑在这上面
2. **纵深一门语言**：前端选 JS/TS + 一个框架；后端选 Java(Spring Boot) 或 Go，精通其核心原理
3. **数据库是硬通货**：SQL 优化 + 索引原理 + 事务隔离级别 + Redis 缓存场景
4. **工程化落地**：构建工具、代码规范、测试、Docker 部署、CI/CD
5. **系统设计拔高**：高并发、分布式事务、幂等、限流降级 —— 面试与架构的分水岭
6. **持续跟进**：AI 集成（LLM/RAG）、云原生、可观测性
