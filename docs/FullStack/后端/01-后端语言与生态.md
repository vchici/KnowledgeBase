# 后端语言与生态

## 主流选型

| 语言 | 框架 | 特点 | 适合 |
|------|------|------|------|
| Java | Spring Boot | 生态最全、稳定、企业级 | 大型业务系统、银行/电商 |
| Go | Gin / Kratos | 高并发、部署简单（单二进制）、性能好 | 中间件、微服务、云原生 |
| Node.js | Express / NestJS | 前后端同语言、I/O 密集 | BFF 层、快速原型 |
| Python | FastAPI / Django | AI 生态强、开发快 | AI 服务、数据平台 |
| Rust | Axum / Actix | 极致性能与安全 | 基础设施、高性能服务 |

> 建议：**精通一门（Java 或 Go），理解其他**。语言是工具，核心是网络、数据库、并发、架构这些不变的知识。

## 语言核心必会（以 Java/Go 为例）

### Java

- JVM 内存模型：堆/栈/方法区、GC 机制（分代回收、G1/ZGC）
- 并发编程：synchronized / ReentrantLock / AQS / 线程池 / volatile / CAS
  - 关联笔记：[synchronized 详解](../../Thread/Lock/synchronized.md)
- 集合框架：ArrayList vs LinkedList、HashMap 原理（数组+链表+红黑树）、ConcurrentHashMap 分段锁/CAS
- Spring 生态：IoC/DI、AOP、Bean 生命周期、事务传播机制
  - 关联笔记：[Spring通关-2-IoC-DI](../../JavaWeb/Spring通关-2-IoC-DI.md)、[Spring通关-4-AOP与数据库](../../JavaWeb/Spring通关-4-AOP与数据库.md)
- 异常体系与日志（SLF4J + Logback）

### Go

- goroutine 与 channel：协程调度（GMP 模型）、CSP 并发模型
  - 关联笔记：[Goroutine](../../JavaWeb/Goroutine.md)
- 指针与值传递、接口（鸭子类型）、错误处理（error 值 vs panic）
- 标准库：net/http、context、sync 包
- 微服务框架：Kratos / Go-zero，rpc（gRPC）

## 后端必会的通用能力

1. **HTTP 服务编程**：路由、中间件、请求上下文、状态码语义
2. **Web 框架原理**：Servlet/Filter/拦截器、AOP 的适用场景
3. **多线程与异步**：线程池参数设计、异步任务、消息驱动
4. **数据访问**：ORM 的用法与 SQL 原生的平衡、事务管理
5. **参数校验与错误处理**：统一响应结构、全局异常处理、参数校验注解/中间件
6. **单元测试与接口测试**：JUnit/Go test、Mock、Testcontainers

## 常见面试题

1. HashMap 底层原理？ConcurrentHashMap 如何保证线程安全？
2. 线程池核心参数（核心线程数、最大线程数、队列、拒绝策略）如何设置？
3. Spring Bean 的生命周期？
4. Spring 事务什么时候会失效？（自调用、异常被吞、传播属性）
5. goroutine 与线程的区别？GMP 调度模型？
6. JVM 内存泄漏如何排查？（关联笔记：[内存泄漏](../../GC/内存泄漏.md)）
