# 机器学习基础（工程视角速览）

> **本质**：机器学习就是「用数据拟合一个函数 f(x)」。工程上真正重要的是三件事：**怎么评估好坏、怎么防止背题（过拟合）、数据怎么喂**。这三件事在 LLM 时代全部沿用。

## 核心考点

### 1. 三种学习范式

- **监督学习**：有标注（分类 / 回归）。标签贵 → 催生了后面的自监督。
- **无监督学习**：无标注，找结构（聚类 K-Means、降维 PCA）。
- **自监督学习**：**自己造标签**——挖词遮词、next-token-prediction。这是整个预训练范式的本质，也是 LLM 能吃下全网数据的唯一原因。
- **强化学习**：无正确答案，只有奖励信号，试错学习。RLHF 的底座。

### 2. 数据划分与评估纪律

- **Train / Val / Test 三分**：val 调参选模型，test 只许碰一次。混用 = 数据泄漏，面试红线题。
- **交叉验证**（K-Fold）：数据少时轮流当验证集。
- **数据泄漏**：测试信息混进训练（时序数据用未来预测过去、特征里含结果）。

### 3. 过拟合 vs 欠拟合

- **欠拟合**：训练集都学不好 → 模型太小 / 特征不够 / 训练不足。
- **过拟合**：训练集好、测试集差 → 模型在「背题」。
- **偏差-方差权衡**：欠拟合=高偏差，过拟合=高方差。
- **正则化手段清单**：L2 权重衰减（压小参数）、L1（稀疏，可做特征选择）、Dropout（随机失活防共适应）、早停（val 开始变差就停）、数据增强（扩充多样性）。**扩数据是治过拟合的根治手段，其余都是缓解。**

### 4. 梯度下降家族

- 批梯度（全量，稳但慢）→ **SGD**（单条，噪声大）→ **mini-batch**（折中，实际标准）。
- 学习率是最重要的超参：太大震荡不收敛，太小慢且易困在局部。
- 进化链：Momentum（惯性）→ AdaGrad/RMSProp（自适应步长）→ **Adam = Momentum + RMSProp**，深度学习默认。

### 5. 评估指标（必背）

- **混淆矩阵**：TP / FP / FN / TN 四格。
- **Accuracy**：整体对的比例。**类别不平衡时是骗局**（99% 负样本下全猜负也有 99%）。
- **Precision 查准**：报出来的里面有多少是对的（误报代价高的场景：垃圾邮件拦截）。
- **Recall 查全**：该抓的抓到了多少（漏报代价高的场景：疾病筛查、风控欺诈）。
- **F1**：Precision 与 Recall 的调和平均，单数字综合。
- **ROC-AUC**：**随机抽一个正样本和一个负样本，正样本得分更高的概率**。与阈值无关，看排序能力。

### 6. 特征工程（了解即可，思想要懂）

- 归一化 / 标准化：让不同量纲特征可比，加速收敛。
- 类别特征：One-Hot（稀疏、维度爆炸）→ **Embedding（稠密低维）**——这条演进路直通 LLM。

## 面试高频速答

### Precision 和 Recall 怎么权衡？

<details>
<summary>答案</summary>
看业务里误报和漏报哪个代价高。调分类阈值即可滑动：阈值高→Precision 高 Recall 低；阈值低→反之。用 PR 曲线或 F1 找平衡点。
</details>

### LLM 时代这些还有用吗？

<details>
<summary>答案</summary>
指标思想全部沿用：RAG 评估的 context recall/precision、对齐评估、分类器路由、有害内容过滤，本质都是这套。只是「模型」变成了 LLM，「特征工程」变成了「上下文工程」。
</details>
