# 深度学习基础（工程视角速览）

> **本质**：用多层非线性变换叠加逼近任意函数（万能逼近）。工程上的全部问题只有两个：**训得动**（梯度能传回来）、**训得稳**（不炸不散）——后面所有组件（残差、Norm、Adam）都是为了这两个字。

## 核心考点

### 1. 神经网络与激活函数

- 线性层叠加还是线性，**必须夹非线性激活**才有表达力。
- 激活函数演进：Sigmoid（饱和、梯度消失）→ ReLU（简单有效，死区问题）→ **GELU / SwiGLU**（平滑版，LLM 标配：LLaMA/Qwen 用 SwiGLU）。
- MLP = 线性层 + 激活，堆 N 层；Transformer 里的 FFN 就是两层 MLP。

### 2. 前向传播与反向传播

- 前向：输入逐层算到损失。反向：**链式法则**把损失对每个参数的梯度从后往前传。
- 工程认知：训练 = 前向算损失 + 反向算梯度 + 优化器更新，三步循环。

### 3. 损失函数

- 回归：MSE / MAE。
- 分类：**交叉熵**（与 softmax 配套），多分类标准答案。LLM 的预训练目标本质也是交叉熵（next token 的分布 vs 真实 token）。

### 4. 优化器进化链（面试爱考「Adam 和 AdamW 区别」）

- SGD → Momentum（动量，惯性冲过小坑）→ RMSProp（自适应步长）→ **Adam**（两者结合）。
- **AdamW**：把 L2 正则从梯度里解耦出来，直接在更新时做权重衰减。Adam 里的 L2 与自适应步长耦合会失效，AdamW 修正了这一点。**Transformer 训练标配 AdamW。**
- **Warmup**：训练初期学习率从 0 线性升上去（初期梯度噪声大、Adam 方差估计不准），再 cosine 衰减。LLM 训练标配。

### 5. 归一化：BN vs LN（高频）

- **BatchNorm**：沿 batch 维度算统计量。问题：变长序列 padding 干扰、batch 小不稳定、推理依赖移动平均。
- **LayerNorm**：沿特征维度算，**与 batch 无关**，适合变长序列 → NLP / Transformer 用 LN。
- **RMSNorm**：LN 的简化版（去均值中心化，只缩放），计算更省，LLaMA 系标配。
- 位置：**Pre-LN**（Norm 放残差分支内部）训练更稳，现代模型都用它。

### 6. 梯度消失 / 爆炸与残差连接

- 深层网络梯度连乘 → 消失（sigmoid 饱和区）或爆炸。
- **残差连接 `y = F(x) + x`**：给梯度一条直通高速路，恒等映射让「加深至少不变差」。Transformer 每个子层都有残差。
- 辅助手段：合理初始化（Xavier/He）、Norm、梯度裁剪（clip，防爆炸，LLM 训练标配）。

### 7. CNN / RNN 简史（为什么被 Transformer 淘汰，一道常考题）

- CNN：局部感受野 + 权重共享，适合图像；但感受野有限，长程依赖要堆很深。
- RNN/LSTM：序列逐步处理，天然适合变长文本；但**串行无法并行** + 长距离信息衰减。
- Transformer 用**自注意力**同时解决两个问题：任意两位置直连（长程依赖）+ 全序列并行计算（可堆大）。→ [04-Transformer与注意力机制](04-Transformer与注意力机制.md)

### 8. 防过拟合的 DL 版

Dropout（注意：LLM 预训练基本不用，靠海量数据本身防过拟合）、权重衰减、早停、数据增强。

## 面试高频速答

### BN 和 LN 的区别？LLM 为什么用 LN/RMSNorm？

<details>
<summary>答案</summary>
BN 沿 batch 维统计，LN 沿特征维统计。序列数据变长 + padding，batch 内统计量不可靠且推理有 train/eval 不一致问题；LN 与 batch 无关逐样本算，适合 NLP。RMSNorm 去掉均值中心化更省算力，效果不掉。
</details>

### AdamW 和 Adam 的区别？

<details>
<summary>答案</summary>
Adam 把 L2 正则混在梯度里，会与自适应步长耦合导致正则失效（大梯度参数反而不受罚）。AdamW 解耦：权重衰减直接乘在权重更新上。训练 Transformer 用 AdamW。
</details>
