# AI 工程导读：四层知识地图

> 本目录面向 **AI 工程应用岗面试**：只收可落地的工程知识，不抠数理推导。目标是「面试官提到的每个概念，你都能接得住并往下讲一层」。

## 一句话定位

**AI 工程 = 把一个「概率性、会出错」的大模型，包装成「可控、可评、可省钱」的在线服务。** 所以整个知识体系都围绕四个问题展开：

1. 模型是什么？（原理层）
2. 模型怎么变小变快？（推理层）
3. 模型不知道的怎么办？（检索层）
4. 模型不可靠怎么办？（应用层）

## 推荐学习路径

1. **赶面试**：`04 → 07 → 08 → 10 → 06 → 13 → 14`，这 7 篇覆盖 90% 高频题。
2. **系统学**：按编号顺序读，基础层写得紧凑，可快速过。
3. **补短板**：面试后哪题卡壳，回来精读对应篇目，再往深度扩写。

## 一句话串联

Tokenizer 把文本切成 token（[03](03-Tokenizer与文本表示.md)），Transformer 用注意力把这些 token 的语义压进千亿参数（[04](04-Transformer与注意力机制.md) / [05](05-预训练与模型格局.md)）；SFT 和 RLHF 教会它好好说话（[06](06-微调与对齐.md)）；部署时用量化、PagedAttention、Continuous Batching 让它又快又省（[08](08-推理优化与部署.md)）；它不知道的知识用向量检索 + RAG 外挂进来（[09](09-Embedding与向量检索.md) / [10](10-RAG系统.md)）；最后靠 Prompt、工具调用、Agent 循环和一整套评估监控，把它变成可靠产品（[11](11-Prompt工程.md) / [12](12-FunctionCalling与MCP.md) / [13](13-Agent架构.md) / [14](14-LLM应用工程实践.md)）。
