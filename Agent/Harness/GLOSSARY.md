# Harness 课程术语表

> 本工作区的规范语言。课程、讲解、学习记录都以这里的术语为准。
> 规则：只有当用户真正理解一个术语后，它才会进入这里——这是压缩后的知识，不是预习用的词典。

## 已确认掌握（开课前已有）

**MCP（Model Context Protocol）**:
模型与外部工具/数据源之间的标准协议，让 harness 以统一方式挂载工具服务器。
_避免_：插件、扩展接口

**上下文窗口（Context Window）**:
模型单次推理能读取的 token 上限，是 harness 必须围绕其做管理的稀缺资源。
_避免_：内存、缓存

**意图识别（Intent Recognition）**:
把自然语言输入解析为结构化意图（如 plan / done / chat）的过程，是编排的分发前提。
_避免_：分类、关键词匹配
